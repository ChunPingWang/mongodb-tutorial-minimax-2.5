# M10: DDD Aggregate 建模

## 模組簡介

本模組將 DDD Aggregate Pattern 落實於 MongoDB Document 設計，涵蓋 Hexagonal Architecture 與 Rich Domain Model。

## 學習目標

- 掌握 Aggregate Root 與 Collection 映射
- 理解 Hexagonal Architecture + MongoDB
- 學習 Rich Domain Model 實踐

## 快速開始

```bash
./gradlew :m10-ddd-aggregate-modeling:test
```
