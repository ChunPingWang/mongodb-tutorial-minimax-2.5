# M02: NoSQL 版圖

## 模組簡介

本模組介紹 NoSQL 資料庫的四大類型：Document Store、Key-Value Store、Wide-Column Store、Graph Database，並深入比較 MongoDB、Redis、Cassandra 的特性與適用場景。

## 學習目標

- 掌握 NoSQL 資料庫類型與特性
- 理解不同資料庫的選型原則
- 學習 Polyglot Persistence 架構

## 內容大綱

### 文件 (DOC)

- **M02-DOC-01**: NoSQL 四大類型全景圖
- **M02-DOC-02**: MongoDB vs Redis vs Cassandra 深度比較
- **M02-DOC-03**: 金融場景 Polyglot Persistence 架構

### 實驗室 (LAB)

- **M02-LAB-01**: 三種 NoSQL 併行測試
- **M02-LAB-02**: Redis 快取 + MongoDB 持久化整合
